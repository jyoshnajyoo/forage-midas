# JPMorgan Chase Software Engineering Job Simulation

## Overview

This project was completed as part of the JPMorgan Chase & Co. Software Engineering Virtual Experience Program on Forage.

The application processes financial transactions using Spring Boot, Apache Kafka, REST APIs, and an H2 database.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Apache Kafka
- REST APIs
- H2 Database
- Maven

## Features

- Kafka Producer and Consumer
- Transaction Processing
- User Balance Management
- REST API Integration
- Incentive Calculation
- Database Persistence

## Skills Demonstrated

- Backend Development
- REST API Development
- Event-Driven Architecture
- Spring Framework
- SQL Database Integration
